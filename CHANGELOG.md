## [0.1.0] - 2025-01-12

### Added
- Initial release of fwen
- Interactive CLI with 5 configuration sections
- Non-interactive mode with full CLI argument support
- Support for Bloc, Provider, Riverpod state management
- Support for GoRouter, AutoRoute, Navigator 2.0
- Support for GetIt, Provider, Riverpod dependency injection
- Template system for modular architecture choices
- Firebase integration templates (Auth, Firestore, Functions, Analytics, Messaging, Storage)
- Authentication setup (Email, Google, Apple, Phone)
- API layer templates (Dio, Retrofit)
- State persistence options (Shared Preferences, Hive, Isar)
- Analytics integration (Firebase Analytics, Sentry, Mixpanel)
- Testing setup support
- CI/CD templates (GitHub Actions, GitLab CI)
- Post-creation actions menu
- Feature generator script
- Multi-platform support (iOS, Android, Web, macOS, Windows, Linux)
- Python 3.11+ support
- uv package manager support
- Comprehensive documentation

### Features
- Clean Architecture scaffolding with core, features, shared layers
- Bootstrap pattern for error handling and initialization
- Configurable project output directory
- Automatic dependency directory creation
- Variable substitution in templates
- Pubspec.yaml dependency merging
- Unit tests with pytest

### Documentation
- Comprehensive README with installation and usage
- Contributing guidelines
- MIT License
- Issue and PR templates
